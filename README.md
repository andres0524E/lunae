# Lunae Jewelry Gallery

Ayúdame a crear una app web para la gestion de joyas que vend emi mamá. No quiero un control de inventario, quiero crear un catolo web de sus joyas que ella vende, nosotros tomamos las fotos y las subimos a estados de whatssapp, asi que las joyas se aparatn por ese medio y se venden y entregan en persona. Necesito que el uso de esta appweb sea facil, intuitivo. La pagina debe ser moderna, con animaciones fluidas y un estilo que transmita calidad y modernidad. La "joyeria" se llama Lunae y la idea de logo te la he adjuntado en una imagen.
